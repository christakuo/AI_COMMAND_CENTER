# Skill：健檢報告分析與健康風險預測

## 使用情境

當使用者提供健檢報告、檢驗數據、血液檢查、影像檢查摘要、企業員工健檢資料時，請使用本 Skill。

本 Skill 適用於：

* 個人健檢報告分析
* 企業員工健檢後續追蹤
* 高風險族群分級
* AI健康管理建議
* 健康顧問追蹤計畫
* 會員健康風險預測
* 企業員工健康風險分層管理

---

## 分析原則

請依照以下順序分析：

---

### 1. 總評摘要

說明整體健康狀況，包含：

* 主要異常項目
* 潛在風險
* 需要優先處理的問題
* 短期健康管理方向
* 中長期健康管理方向

請用專業但容易理解的語氣說明，不要製造恐慌。

---

### 2. 異常數值整理

請用表格呈現：

| 項目 | 數值 | 參考區間 | 異常狀態 | 可能意義 | 建議 |
| -- | -- | ---- | ---- | ---- | -- |

如果沒有提供參考區間，請標註：

> 需依檢驗單位標準判讀。

若資料不足，請明確列出缺少的檢驗項目或基本資料。

---

### 3. 風險分級

請依照健檢資料，將健康狀況分成：

* 低風險
* 中風險
* 高風險
* 需優先追蹤

請說明每一項風險分級的原因。

建議用表格呈現：

| 風險項目 | 風險等級 | 判斷依據 | 建議處理方向 |
| ---- | ---- | ---- | ------ |

---

### 4. 健康問題分類

請依照以下類別整理：

* 代謝風險
* 心血管風險
* 肝腎功能
* 發炎與免疫
* 荷爾蒙與內分泌
* 腸胃與消化
* 睡眠與壓力
* 體重與體脂管理
* 癌症風險提醒
* 長照與高齡健康風險

請針對每一類別說明：

* 目前是否有異常
* 與哪些檢驗數據或生活型態有關
* 是否需要追蹤
* 建議改善方向

---

### 5. 健康風險預測分析

請根據目前健檢資料，進行健康風險分層與未來追蹤建議。

本分析不是疾病診斷，也不是保證性預測，而是作為健康管理與預防醫學參考。

請分析以下風險：

| 風險類別 | 目前相關指標 | 風險等級 | 可能發展方向 | 建議追蹤 |
| ---- | ------ | ---- | ------ | ---- |

風險類別包含：

#### 5.1 心血管疾病風險

參考指標：

* 血壓
* 總膽固醇
* LDL-C
* HDL-C
* 三酸甘油脂
* 血糖
* HbA1c
* 抽菸
* 年齡
* 性別
* 家族史
* BMI
* 腰圍

分析重點：

* 是否有高血壓風險
* 是否有血脂異常風險
* 是否有動脈硬化或心血管疾病風險
* 是否需要進一步做頸動脈超音波、心臟超音波、冠狀動脈鈣化指數或其他醫師建議檢查

若資料充足，可提醒可使用 WHO CVD Risk Chart 或 AHA PREVENT 類型風險模型作進一步估算。

若資料不足，請列出缺少哪些資料。

---

#### 5.2 糖尿病與代謝症候群風險

參考指標：

* 空腹血糖
* HbA1c
* 胰島素
* BMI
* 腰圍
* 三酸甘油脂
* HDL-C
* 血壓
* 家族史
* 運動習慣

分析重點：

* 是否有糖尿病前期風險
* 是否有胰島素阻抗風險
* 是否有代謝症候群風險
* 是否需要進一步追蹤血糖、HbA1c 或胰島素阻抗相關指標

---

#### 5.3 脂肪肝與肝功能異常風險

參考指標：

* GOT / AST
* GPT / ALT
* γ-GT
* 腹部超音波
* 三酸甘油脂
* BMI
* 腰圍
* 飲酒習慣
* B型肝炎與C型肝炎指標

分析重點：

* 是否有脂肪肝風險
* 是否有肝功能異常
* 是否與體重、血脂、飲酒或病毒性肝炎相關
* 是否需要胃腸肝膽科追蹤

---

#### 5.4 腎功能風險

參考指標：

* 肌酸酐
* eGFR
* 尿蛋白
* 尿潛血
* 血壓
* 血糖
* 尿酸

分析重點：

* 是否有腎功能下降風險
* 是否有蛋白尿或尿液異常
* 是否與血壓、血糖、尿酸相關
* 是否需要腎臟科或家庭醫學科追蹤

---

#### 5.5 慢性發炎與免疫風險

參考指標：

* hs-CRP
* 白血球分類
* ESR
* 同半胱胺酸
* 生活壓力
* 睡眠狀態
* 自律神經狀態

分析重點：

* 是否有慢性發炎狀態
* 是否與壓力、睡眠、肥胖、代謝異常或感染有關
* 是否需要生活型態調整或進一步檢查

---

#### 5.6 癌症風險提醒

參考指標：

* 年齡
* 性別
* 家族史
* 抽菸
* 飲酒
* 肥胖
* 糞便潛血
* 肝炎指標
* 影像檢查
* 腫瘤標記

分析重點：

* 不可用腫瘤標記直接判斷癌症
* 不可宣稱已罹患或未罹患癌症
* 請以篩檢提醒、醫師評估與定期追蹤為主
* 若有異常影像或高風險家族史，應建議由醫師進一步評估

---

#### 5.7 高齡與長照風險

參考指標：

* 年齡
* 肌少症風險
* 骨密度
* 跌倒史
* 慢性病數量
* 認知功能
* 日常活動能力
* 家庭照護支持

分析重點：

* 是否有肌少症風險
* 是否有骨質疏鬆或跌倒風險
* 是否有多重慢性病管理需求
* 是否需要長照資源、復健、營養或居家照護評估

---

每一項風險請輸出：

* 風險等級：低 / 中 / 高 / 需優先追蹤
* 判斷依據
* 可能影響
* 建議改善方向
* 建議追蹤時間
* 是否建議轉介醫師或專科

---

### 6. 改善計畫

請根據異常數值、風險分級與健康風險預測結果，提出改善計畫。

內容包含：

* 飲食建議
* 運動建議
* 睡眠建議
* 壓力管理
* 體重與體脂管理
* 保健食品或營養補充方向
* 是否需要醫師門診追蹤
* 是否需要複檢

請避免宣稱保健食品或營養補充品可以治療疾病。

建議用表格呈現：

| 改善面向 | 建議內容 | 執行方式 | 預期目標 |
| ---- | ---- | ---- | ---- |

---

### 7. 追蹤時程

請提供具體追蹤時程：

| 時間    | 建議行動 |
| ----- | ---- |
| 1個月內  |      |
| 3個月內  |      |
| 6個月內  |      |
| 12個月內 |      |

請依照風險程度調整追蹤頻率。

若屬於高風險或需優先追蹤者，請建議提早就醫或複檢。

---

### 8. 給會員的白話版說明

請將專業內容轉成一般會員聽得懂的語氣。

語氣需：

* 溫暖
* 專業
* 不恐嚇
* 有行動方向
* 避免過度醫療化
* 避免使用艱深術語

請用會員容易理解的方式說明：

* 目前最需要注意的是什麼
* 為什麼需要注意
* 接下來可以怎麼改善
* 何時需要追蹤或就醫

---

### 9. 醫師追蹤與複檢建議

請根據異常項目與風險分級，提出是否需要醫師評估、專科轉介或複檢。

請用表格呈現：

| 追蹤項目 | 建議科別 | 建議時間 | 追蹤原因 | 注意事項 |
| ---- | ---- | ---- | ---- | ---- |

建議科別可包含：

* 家庭醫學科
* 心臟內科
* 新陳代謝科
* 胃腸肝膽科
* 腎臟科
* 婦產科
* 泌尿科
* 腫瘤科
* 營養師
* 運動醫學或復健科

請避免製造恐慌，語氣應以：

* 建議進一步確認
* 建議定期追蹤
* 建議與醫師討論
* 建議安排複檢

為主。

## 注意事項

* 不可直接診斷疾病
* 不可宣稱可以治療疾病
* 不可取代醫師診斷
* 不可用單一數值判定疾病
* 不可用腫瘤標記直接判斷癌症
* 若出現明顯危險訊號，應提醒儘速就醫
* 若資料不足，請先要求補充資料
* 所有建議應以健康管理、預防醫學、生活型態改善與醫師追蹤為主
* 若涉及藥物、治療或醫療處置，請建議由醫師評估
