## 長照資源整合基本原則

長照資源整合不是醫療診斷，也不是政府長照資格判定，而是協助會員或家屬初步整理需求、釐清問題、安排下一步資源諮詢。

規劃時應考量：

| 評估面向     | 說明                      |
| -------- | ----------------------- |
| 會員基本狀況   | 年齡、性別、居住地、同住者、主要照顧者     |
| 健康與疾病狀況  | 慢性病、失能狀況、術後復健、跌倒風險、認知狀況 |
| 日常生活功能   | 進食、洗澡、如廁、穿衣、移位、行走       |
| 工具性日常功能  | 購物、備餐、家務、服藥、交通、財務管理     |
| 家庭照護能力   | 家屬時間、人力、經濟能力、照護壓力       |
| 居家環境     | 樓梯、浴室安全、動線、床位、輔具需求      |
| 醫療與復健需求  | 門診、復健、傷口照護、營養、用藥管理      |
| 長照資源需求   | 居家服務、日照中心、喘息服務、交通接送、輔具  |
| 外籍看護需求   | 是否需長時間照護、家屬是否可負擔管理責任    |
| 企業員工家庭照護 | 員工是否因照護長輩影響工作、出勤或壓力     |

## 長照需求分級

請將需求分為以下 5 類：

| 等級 | 名稱       | 定位                       |
| -- | -------- | ------------------------ |
| L1 | 健康預防型    | 尚未失能，以預防跌倒、肌力維持、健康促進為主   |
| L2 | 輕度支持型    | 有部分生活協助需求，可透過居家服務或家屬支持改善 |
| L3 | 中度照護型    | 需要固定照護安排、復健、日照或居家服務      |
| L4 | 高度照護型    | 需要密集照護、長時間陪伴或外籍看護評估      |
| L5 | 資料不足待評估型 | 資料不足，需補充健康、功能或家庭照護資訊     |

---

## L1：健康預防型

### 判斷條件

符合以下情況，可列為 L1：

* 生活可自理
* 無明顯失能或照護需求
* 有中高齡健康管理需求
* 有慢性病風險但功能尚可
* 有肌力下降、活動量不足或跌倒預防需求
* 家屬希望提前規劃長照與健康管理

### 服務目標

* 維持生活功能
* 預防跌倒
* 延緩肌力下降
* 建立規律運動與營養管理
* 定期健檢與健康追蹤
* 提前認識長照資源

### 建議資源

* 肌力訓練
* 營養諮詢
* 跌倒預防衛教
* 年度健檢
* 慢性病風險管理
* LINE 健康提醒

---

## L2：輕度支持型

### 判斷條件

符合以下任一情況，可列為 L2：

* 部分家務或外出需要協助
* 偶爾需要陪診或交通接送
* 有輕度行動不便
* 有跌倒風險
* 家屬有照護壓力但尚可自行照顧
* 需要初步居家安全改善

### 服務目標

* 協助維持居家生活
* 降低跌倒及意外風險
* 支持主要照顧者
* 提供適度居家服務或交通協助
* 建立定期關懷與追蹤

### 建議資源

* 居家安全檢視
* 扶手、防滑、照明改善
* 交通接送
* 陪診服務
* 居家服務
* 照護者支持諮詢

---

## L3：中度照護型

### 判斷條件

符合以下任一情況，可列為 L3：

* 日常生活部分項目需要協助
* 需要固定復健或照護安排
* 有術後復健需求
* 有慢性病合併功能下降
* 需要日間照顧、居家服務或喘息服務
* 家屬照護負擔明顯增加

### 服務目標

* 建立固定照護安排
* 維持或改善生活功能
* 減輕家屬照護壓力
* 協助連結居家服務、復健、日照或喘息資源
* 定期追蹤照護成效

### 建議資源

* 居家照護
* 居家復健
* 日照中心
* 喘息服務
* 輔具評估
* 營養與吞嚥評估
* 家屬照護指導

---

## L4：高度照護型

### 判斷條件

符合以下任一情況，可列為 L4：

* 多項日常生活功能需要協助
* 長時間無法獨處
* 需要密集照護或夜間照護
* 有失智、臥床、反覆跌倒或吞嚥困難等高照護需求
* 家屬無法負荷照護
* 可能需要外籍看護、24小時照護或機構式照護評估

### 服務目標

* 確保基本安全與照護連續性
* 協助家屬釐清照護模式
* 評估外籍看護、居家照護或機構式照護需求
* 協助安排專業諮詢
* 減輕主要照顧者壓力

### 建議資源

* 外籍看護需求評估
* 居家照護服務
* 護理照護資源
* 機構式照護資訊
* 輔具與居家環境調整
* 照顧者喘息支持
* 長照專業諮詢

---

## L5：資料不足待評估型

### 判斷條件

符合以下任一情況，應列為 L5：

* 未提供年齡、居住地或同住者資訊
* 未提供日常生活功能狀況
* 未提供疾病、用藥或近期就醫狀況
* 未提供主要照顧者資訊
* 未提供家庭照護壓力或需求
* 無法判斷是否需要長照資源
* 會員或家屬需求描述不清楚

### 服務目標

* 補齊基本資料
* 釐清照護需求
* 不進行無依據判斷
* 補充資料後重新分級

### 建議補充資料

* 年齡與居住地
* 同住者與主要照顧者
* 疾病與用藥
* 日常生活功能
* 行動能力與跌倒史
* 認知與情緒狀況
* 家屬照護壓力
* 目前已使用的照護資源

## 12. 注意事項與合規提醒

### 長照與照護內容

* 本分析僅供長照資源初步整理與健康管理參考。
* 不取代醫師、社工師、照管專員或政府長照單位評估。
* 不保證可取得特定補助、服務名額或資格。
* 不應以不完整資料直接判斷失能等級。
* 如有急性症狀、跌倒受傷、意識改變、呼吸困難或嚴重疼痛，應儘速就醫。

### 個資與轉介

* 轉介前需取得會員或家屬同意。
* 應說明轉介目的與資料使用範圍。
* 不得將健康資料用於會員或家屬未同意的用途。
* 不得將資料提供給未經同意的第三方。
* 長照資源轉介紀錄應保留同意狀態、轉介對象、提供資料範圍及後續狀態。

### 外籍看護相關

* 外籍看護需求僅能作為初步需求整理。
* 實際資格、申請流程、文件與審核結果，應由合法專業單位或相關主管機關依規定辦理。
* 不保證可成功申請外籍看護。
* 不得以不實或誇大方式宣稱可保證媒合人力。

## 常見長照情境範本

### 情境 1：家屬詢問長輩是否需要長照

| 項目   | 內容                          |
| ---- | --------------------------- |
| 可能需求 | 需先確認日常生活功能、行動能力、疾病狀況與家庭照護能力 |
| 初步建議 | 建議先填寫長照需求評估表                |
| 下一步  | 可由專人協助整理需求並建議適合資源方向         |

LINE 回覆範例：

您好，若家中長輩開始出現行動不便、需要陪診、家務協助或家屬照護壓力增加，建議先做一次長照需求初步評估。
回覆「長照」，我們可協助您整理目前需求與下一步資源方向。

---

### 情境 2：術後復健與居家照護需求

| 項目   | 內容                  |
| ---- | ------------------- |
| 可能需求 | 復健、陪診、居家照護、輔具、交通接送  |
| 初步建議 | 先確認醫師復健建議、行動能力與居家環境 |
| 下一步  | 建議安排復健或居家照護資源諮詢     |

LINE 回覆範例：

術後返家後，常見需求包括復健、陪診、交通接送、居家安全與家屬照護安排。
回覆「復健」，我們可協助您整理目前狀況，提供下一步資源建議。

---

### 情境 3：家屬照護壓力大

| 項目   | 內容                  |
| ---- | ------------------- |
| 可能需求 | 喘息服務、照護分工、日照中心、居家服務 |
| 初步建議 | 先確認主要照顧者負擔與長輩日常功能   |
| 下一步  | 建議安排照護資源諮詢          |

LINE 回覆範例：

照顧家人是一件很辛苦的事。若您已經感到疲累、睡眠受影響或無法兼顧工作與照護，可以先整理目前照護壓力與需要協助的項目。
回覆「家屬」，我們可協助您了解可討論的照護資源方向。

---

### 情境 4：企業員工家庭照護支持

| 項目   | 內容                       |
| ---- | ------------------------ |
| 可能需求 | 員工家屬照護諮詢、長照資源講座、家庭照護支持方案 |
| 初步建議 | 將長照資源納入員工健康促進與 ESG 社會支持  |
| 下一步  | 規劃企業長照資源講座或員工諮詢服務        |

企業提案文字範例：

隨著中高齡家庭照護需求增加，員工可能因父母照護、陪診、復健或長照安排而承受壓力。企業可將長照資源諮詢納入員工健康促進方案，協助員工取得正確資訊，降低家庭照護壓力，並展現企業對員工與家庭的支持。
