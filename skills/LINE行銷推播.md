# Skill：LINE行銷推播

## 使用情境

當使用者需要建立 LINE 官方帳號推播內容、會員經營訊息、健康提醒、健檢提醒、活動通知、衛教內容、報告上傳提醒、健檢後追蹤訊息、保險顧問轉介提醒或健康管理服務推廣時，請使用本 Skill。

本 Skill 適用於：

* 元馨醫管家官方 LINE及會員經營
* AI馨健康官方 LINE及會員經營
* 健檢前提醒
* 健檢後報告追蹤
* 健康講座推播
* 會員健康管理提醒
* 高風險會員追蹤
* 保險顧問轉介提醒
* 長照資源推播
* 健康管理服務行銷

## LINE 推播基本原則

### 1. 訊息需短而清楚

LINE 推播不適合長篇文章。

每則訊息建議：

* 標題：15 字以內
* 主文：80～180 字
* CTA：1 個明確行動
* 若內容較長，請拆成多則訊息

---

### 2. 每則訊息需有明確目的

請先判斷推播目的：

| 推播目的 | 內容方向             |
| ---- | ---------------- |
| 提醒   | 健檢前提醒、報告上傳、複檢提醒  |
| 教育   | 健康知識、疾病預防、生活習慣改善 |
| 互動   | 問卷、回覆關鍵字、預約諮詢    |
| 轉換   | 預約健檢、加入會員、報名講座   |
| 追蹤   | 健檢後改善計畫、健康管理師追蹤  |
| 轉介   | 保險顧問、長照資源、醫師諮詢   |

---

### 3. 避免醫療與保險高風險用語

不可使用：

* 保證改善
* 保證治療
* 一定有效
* 診斷你有某疾病
* 你一定會罹患某疾病
* 買這個保險最適合你
* 保證可理賠
* 保證可承保
* 保證核保通過

建議使用：

* 建議進一步確認
* 建議定期追蹤
* 可作為健康管理參考
* 可與醫師討論
* 可與合格保險專業人員討論
* 若有不適，請儘速就醫

## 1. 推播目的

請先說明此推播的目的，例如：

* 提醒會員上傳健檢報告
* 邀請會員預約健檢
* 提醒會員完成複檢
* 邀請會員報名健康講座
* 推廣企業員工健檢服務
* 提醒高風險會員進行健康追蹤
* 引導會員了解保險保障缺口
* 提醒會員同意後可安排保險顧問諮詢
* 提供長照資源或高齡照護提醒

---

## 2. 目標受眾

請清楚定義目標受眾：

| 受眾類型     | 說明               |
| -------- | ---------------- |
| 一般會員     | 已加入 LINE，但尚未預約健檢 |
| 健檢會員     | 已完成健檢或已預約健檢      |
| 報告上傳會員   | 已上傳健檢報告，等待分析     |
| 高風險會員    | 健檢後需要追蹤者         |
| 企業員工     | 企業健檢或職場健康促進對象    |
| 保險業務合作客戶 | 由保險業務轉介或共同服務對象   |
| 中高齡會員    | 有長照、慢病、照護資源需求者   |
| 潛在客戶     | 尚未加入會員或尚未使用服務者   |

---

## 3. 推播情境

請說明此推播適合用於哪個情境，例如：

* 加入好友後第 1 則歡迎訊息
* 健檢前 7 天提醒
* 健檢前 1 天提醒
* 健檢後 3 天報告上傳提醒
* 報告分析完成通知
* 高風險會員追蹤提醒
* 複檢前 7 天提醒
* 健康講座前 3 天提醒
* 會員服務介紹
* 保險保障缺口分析後提醒
* 長照資源諮詢提醒

---

## 4. LINE 推播文案

請產出至少 3 種版本：

### A. 溫暖提醒版

適合既有會員、健檢後追蹤、複檢提醒。

### B. 專業信任版

適合健康管理、健檢報告分析、企業客戶。

### C. 行動轉換版

適合預約健檢、報名講座、填寫表單、安排諮詢。

每一版需包含：

| 元素  | 內容         |
| --- | ---------- |
| 標題  | 15 字以內     |
| 主文  | 80～180 字   |
| CTA | 明確行動       |
| 關鍵字 | 建議會員回覆的關鍵字 |

* 回覆「保險」了解保障缺口分析
* 回覆「長照」了解長照資源

| 長照資源追蹤 | 會員提出需求後 1～3 天內   |

## 9. 後續追蹤流程

請設計推播後的追蹤流程：

| 會員反應      | 後續流程          |
| --------- | ------------- |
| 已讀未回      | 3～7 天後發送第二次提醒 |
| 回覆關鍵字     | 自動回覆並標籤分類     |
| 點擊連結未完成表單 | 1～3 天後提醒      |
| 完成表單      | 指派健康管理師聯繫     |
| 高風險會員     | 轉健康管理師追蹤      |
| 同意保險顧問轉介  | 建立轉介紀錄並通知顧問   |
| 不同意轉介     | 不再提供保險相關追蹤    |
| 提出長照需求    | 轉長照資源諮詢流程     |

## 10. 合規注意事項

### 醫療健康內容

請遵守：

* 不可直接診斷疾病
* 不可宣稱可以治療疾病
* 不可保證改善結果
* 不可製造恐慌
* 不可取代醫師診斷
* 若有明顯不適或危險訊號，應提醒就醫

### 保險相關內容

請遵守：

* 不可推薦特定保險公司
* 不可推薦特定保險商品
* 不可建議特定保費或保額
* 不可保證可以投保
* 不可保證可以承保
* 不可保證可以理賠
* 不可作為保險招攬文件
* 不可作為投保建議書
* 不可作為核保結果判斷依據
* 會員同意前，不得將健康資料提供給保險顧問

### 個資與資料使用

請遵守：

* 轉介前需取得會員同意
* 應說明轉介目的
* 應說明資料使用範圍
* 不得將健康資料用於會員未同意的用途
* 不得將資料提供給未經會員同意的第三方

## 常見推播範本

### 1. 歡迎新好友

**標題：歡迎加入元馨醫管家**

您好，歡迎加入元馨醫管家。
我們提供健檢預約、報告分析、健康管理與後續追蹤服務，協助您更清楚了解自己的健康狀況。

回覆「健檢」，了解適合您的健檢服務。

---

### 2. 健檢報告上傳提醒

**標題：記得上傳報告**

您好，若您已完成健康檢查，歡迎上傳健檢報告。
我們將協助您整理異常項目、健康風險與後續追蹤方向，作為健康管理參考。

回覆「報告」，取得上傳連結。

---

### 3. 報告分析完成通知

**標題：報告分析完成**

您的健檢報告分析已完成。
本次分析將協助您了解主要異常項目、健康風險、改善方向與追蹤建議。

回覆「健管」，了解後續健康管理服務。

---

### 4. 高風險追蹤提醒

**標題：健康追蹤提醒**

您的健檢結果中有部分項目建議持續追蹤。
本提醒僅作為健康管理參考，若有不適或醫師建議，請優先安排就醫或複檢。

回覆「複檢」，查看追蹤建議。

---

### 5. 健康講座邀請

**標題：健康講座邀請**

本月健康講座主題為預防醫學與健康管理。
歡迎您一起了解如何從健檢結果出發，建立更適合自己的健康改善計畫。

回覆「講座」，取得報名資訊。

---

### 6. 保險保障缺口提醒

**標題：保障缺口提醒**

健檢報告可協助了解健康風險，也能作為檢視保障需求的參考。
本服務僅協助整理可能的保障缺口方向，不構成保險商品推薦或投保建議。

若您希望進一步了解，可回覆「保險」，由專人說明資料使用與轉介流程。

---

### 7. 長照資源提醒

**標題：長照資源諮詢**

若家中長輩有照護、復健、失能評估或居家服務需求，元馨醫管家可協助初步整理需求並提供資源諮詢方向。

回覆「長照」，了解可協助的服務內容。
