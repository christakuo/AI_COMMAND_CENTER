# Skills 中心

本資料夾存放可重複使用的 AI 工作技能。

每一個 Skill 都是一套標準作業流程，讓 Codex 在執行任務時，可以依照固定規則產出穩定結果。

本資料夾的目標是讓 Codex 成為元馨健康生活事業的 AI 工作助理，協助處理：

* 企業健康管理提案
* 健檢報告分析
* 健康風險預測
* LINE 行銷推播
* 會員分級管理
* 長照資源整合提案

## 使用方式

當使用者要求 Codex 執行某項任務時，請先讀取相關 Skill 文件，再開始產出內容。

例如：

* 企業 ESG 健康管理提案
  → 讀取 `skills/企業ESG健康管理提案.md`

* 健檢報告分析、健康風險預測、會員健康管理建議
  → 讀取 `skills/健檢報告分析與健康風險預測.md`

  → 讀取 `skills/LINE行銷推播.md`

* 會員分級、健康追蹤、顧問服務規劃
  → 讀取 `skills/健康管理會員分級.md`

  → 讀取 `skills/長照資源整合提案.md`

## Codex 執行原則

當使用者提出任務時，請依照以下流程：

1. 先判斷任務類型
2. 找出應該讀取的 Skill 文件
3. 讀取必要的公司背景文件
4. 依照 Skill 的標準流程產出內容
5. 若資料不足，先列出需要補充的問題
6. 不要自行捏造醫療數據、企業資料或報價金額
7. 若涉及醫療判斷，應以健康管理建議與就醫追蹤建議呈現
8. 不可直接診斷疾病
9. 不可宣稱可以治療疾病
10. 不可取代醫師診斷

## 維護原則

1. 若新增 Skill，請同步更新本 README。
2. 若 Skill 名稱修改，請同步修改「使用方式」與「Skill 對應任務表」。
3. 若某個 Skill 已經不再使用，請標註為「暫停使用」，不要直接刪除。
4. 若 Skill 涉及醫療、財務、法律或高風險判斷，請加入注意事項。
5. 所有醫療相關 Skill 都必須保留以下原則：

* 不可直接診斷疾病
* 不可宣稱可以治療疾病
* 不可取代醫師診斷
* 若出現明顯危險訊號，應提醒儘速就醫
* 若資料不足，請先要求補充資料
