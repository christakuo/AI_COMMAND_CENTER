# Skill：健康管理會員分級

## 使用情境

當使用者需要根據會員的健檢結果、健康風險、生活型態、年齡、追蹤需求、醫師複檢需求、LINE 標籤、健康管理服務、保險顧問轉介或長照資源需求，進行會員分級與後續管理規劃時，請使用本 Skill。

本 Skill 適用於：

* 元馨醫管家會員健康管理
* AI馨健康會員分級
* 健檢後會員追蹤
* 高風險會員管理
* LINE 分眾標籤設計
* 健康管理師追蹤任務
* 企業員工健檢後分級
* 保險顧問轉介名單整理
* 長照與高齡健康風險分流
* 會員續約與加值服務設計

## 分級基本原則

會員分級不是醫療診斷，而是健康管理與服務追蹤的優先順序設計。

分級時應考量：

| 評估面向    | 說明                       |
| ------- | ------------------------ |
| 健檢異常項目  | 是否有多項異常、明顯偏高或偏低          |
| 健康風險    | 代謝、心血管、肝腎、癌症篩檢、高齡長照等風險   |
| 年齡與生活型態 | 年齡、BMI、腰圍、血壓、抽菸、飲酒、運動、睡眠 |
| 醫師複檢需求  | 是否需安排門診、影像檢查、抽血追蹤        |
| 健康管理需求  | 是否需要飲食、運動、體重、慢性病風險管理     |
| 會員互動狀態  | 是否已加入 LINE、是否上傳報告、是否回覆推播 |
| 服務轉換機會  | 是否適合健康管理方案、講座、健檢續約       |
| 保險缺口需求  | 是否有保障缺口討論需求，且會員是否同意轉介    |
| 長照或高齡需求 | 是否有照護、失能、復健、居家服務需求       |

## 會員分級架構

請將會員分為以下 5 個等級：

| 等級 | 名稱        | 定位                    |
| -- | --------- | --------------------- |
| A級 | 高風險重點追蹤會員 | 需要優先健康管理師追蹤與醫師複檢提醒    |
| B級 | 中高風險管理會員  | 需要定期追蹤與生活型態改善         |
| C級 | 一般健康管理會員  | 有輕度異常或健康管理需求          |
| D級 | 健康維持會員    | 健檢狀況穩定，以維持與預防為主       |
| E級 | 資料不足待補件會員 | 資料不足，需補充健檢報告或基本資料後再分級 |

---

## A級：高風險重點追蹤會員

### 判斷條件

符合以下任一情況，可列為 A級：

* 多項重大異常或高風險指標
* 血壓、血糖、血脂、肝腎功能等明顯異常
* 醫師建議儘速複檢或門診追蹤
* 有明顯症狀或危險訊號
* 健檢影像發現需進一步檢查
* 癌症篩檢異常需醫師評估
* 高齡會員合併多項慢性病風險
* 需要健康管理師密集追蹤
* 會員有明確保險或長照資源需求，且健康風險較高

### 管理目標

* 優先確認異常項目
* 協助安排醫師門診或複檢
* 建立 1～3 個月密集追蹤
* 協助健康管理師追蹤飲食、運動、用藥與生活型態
* 必要時評估保險顧問或長照資源轉介，但需取得會員同意

### LINE 標籤建議

* 高風險追蹤
* 優先複檢
* 健康管理師追蹤
* 醫師門診建議
* 保險顧問轉介待確認
* 長照資源需求待確認

---

## B級：中高風險管理會員

### 判斷條件

符合以下任一情況，可列為 B級：

* 有 2～3 項以上中度異常
* 有代謝症候群、脂肪肝、血脂異常、血糖偏高等風險
* BMI 或腰圍偏高，且合併其他風險因子
* 睡眠、壓力、運動不足明顯影響健康
* 需要 3～6 個月追蹤改善成效
* 有家庭病史或慢性病風險
* 有保障缺口檢視需求，但尚未進入高風險追蹤

### 管理目標

* 建立 3～6 個月改善計畫
* 定期追蹤體重、腰圍、血壓、血糖或血脂
* 推送健康教育與生活型態改善內容
* 提醒複檢與年度健檢
* 引導加入健康管理服務

### LINE 標籤建議

* 中高風險管理
* 代謝風險
* 體重管理
* 血脂血糖追蹤
* 健管服務推薦
* 複檢提醒

---

## C級：一般健康管理會員

### 判斷條件

符合以下任一情況，可列為 C級：

* 有輕度異常但未達高風險
* 健康狀況大致穩定，但有改善空間
* 有體重、飲食、運動、睡眠或壓力管理需求
* 對健康講座、營養諮詢、健康管理有興趣
* 已完成健檢，但尚未加入持續追蹤服務

### 管理目標

* 提供一般健康管理建議
* 促進健康生活習慣
* 推送健康講座、衛教內容與會員服務
* 引導下一次年度健檢
* 提升會員互動與續約機會

### LINE 標籤建議

* 一般健康管理
* 健康講座
* 生活型態改善
* 年度健檢提醒
* 會員經營

---

## D級：健康維持會員

### 判斷條件

符合以下情況，可列為 D級：

* 健檢結果大致正常
* 無明顯高風險異常
* 生活型態穩定
* 主要需求為健康維持、預防保健與年度健檢
* 適合定期健康提醒與會員關係維護

### 管理目標

* 維持健康狀態
* 提醒年度健檢
* 提供預防醫學與健康知識
* 鼓勵持續運動、均衡飲食與睡眠管理
* 增加會員黏著度

### LINE 標籤建議

* 健康維持
* 年度健檢
* 預防保健
* 健康知識推播
* 低風險會員

---

## E級：資料不足待補件會員

### 判斷條件

符合以下任一情況，應列為 E級：

* 未提供完整健檢報告
* 缺少年齡、性別、身高、體重、BMI、腰圍、血壓等基本資料
* 缺少主要檢驗數值或參考區間
* 缺少生活型態資料
* 缺少既往病史、家族史或用藥資訊
* 健檢報告影像、文字或表格不清楚
* 無法判斷風險等級

### 管理目標

* 引導會員補充資料
* 提供報告上傳說明
* 不進行無依據分級
* 補齊資料後再重新分級

### LINE 標籤建議

* 資料不足
* 待補報告
* 待補基本資料
* 報告上傳提醒
* 需重新評估

## 注意事項

* 本分級僅供健康管理與服務追蹤使用，不取代醫師診斷。
* 不得根據不完整資料進行無依據推論。
* 如資料不足，應列為 E級或標示需補充資料。
* 若有明顯危險訊號，應建議會員儘速就醫。
* 保險顧問轉介前，必須取得會員同意。
* 健康資料不得提供給未經會員同意的第三方。
* 長照資源轉介應以會員或家屬實際需求為準。
* 對企業員工資料進行分級時，應避免揭露可識別個人健康資訊給企業端。
