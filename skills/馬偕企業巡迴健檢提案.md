# Skill：馬偕企業巡迴健檢提案

## 使用情境

當使用者需要針對企業客戶規劃「馬偕醫院企業巡迴健檢」服務、企業員工年度健檢、企業到場巡迴健檢、HR 採購提案、員工健檢說明會、企業健康促進方案、健檢後團體統計分析或 ESG 健康促進延伸方案時，請使用本 Skill。

本 Skill 適用於：

* 馬偕醫院企業巡迴健檢服務提案
* 企業員工年度健檢規劃
* 企業到場巡迴健檢服務設計
* 廠護／職安／HR／福委會／總務採購提案
* 企業員工健檢說明會內容
* 員工健檢流程規劃
* 健檢後報告交付與異常追蹤提醒
* 企業員工健康風險統計分析
* 去識別化團體健康報告
* 企業 ESG 健康促進延伸方案
* 金融業、科技業、製造業、公部門企業健檢合作提案

## 4. 健檢項目與方案設計

請依企業預算、員工年齡層、產業風險與醫院實際可執行項目設計方案。

### 基礎方案

適合一般員工年度健檢。

| 類別    | 項目                  |
| ----- | ------------------- |
| 基本量測  | 身高、體重、BMI、腰圍、血壓     |
| 血液檢查  | 血糖、血脂、肝功能、腎功能、尿酸、血球 |
| 尿液檢查  | 尿蛋白、尿糖、尿潛血等         |
| 影像或功能 | 依企業預算與醫院方案安排        |
| 醫師問診  | 依院方流程               |

### 進階方案

適合主管、40歲以上員工或高風險族群。

| 類別    | 項目方向              |
| ----- | ----------------- |
| 心血管風險 | 心電圖、頸動脈、心血管風險因子   |
| 代謝風險  | HbA1c、代謝相關指標      |
| 肝膽腸胃  | 腹部超音波、肝炎指標        |
| 癌症篩檢  | 依年齡、性別、家族史與醫師建議規劃 |
| 壓力與睡眠 | 問卷、壓力或睡眠風險評估視需求   |

### 客製化加選

| 加選方向    | 適合對象               |
| ------- | ------------------ |
| 低劑量肺部CT | 吸菸史或肺癌高風險員工，需依醫師建議 |
| 腸胃鏡     | 中高齡或腸胃風險族群         |
| 女性健康    | 乳房、婦科、骨密度等         |
| 高階主管健檢  | 深度影像、心血管、腫瘤風險、個人健管 |
| 職場壓力方案  | 高壓職務、金融業、科技業、主管群   |

## 6. 企業與員工溝通流程

請規劃健檢前、中、後的溝通。

| 時間     | 溝通對象 | 溝通內容           | 工具              |
| ------ | ---- | -------------- | --------------- |
| 健檢前30天 | HR   | 名冊、方案、場地、時程確認  | 會議／Email        |
| 健檢前14天 | 員工   | 健檢通知、注意事項、預約時段 | Email／LINE／企業公告 |
| 健檢前7天  | 員工   | 禁食、攜帶證件、報到時間   | LINE／Email／公告   |
| 健檢前1天  | 員工   | 最後提醒           | LINE／Email      |
| 健檢當日   | 員工   | 報到、動線、檢查說明     | 現場人員            |
| 健檢後    | 員工   | 報告領取、異常追蹤提醒    | Email／LINE／院方流程 |
| 健檢後    | HR   | 團體統計與健康促進建議    | 簡報／報告           |

## 12. 風險控管與注意事項

| 風險        | 控管方式             |
| --------- | ---------------- |
| 員工報到混亂    | 預約分流、明確動線、現場引導   |
| 健檢等待過久    | 分時段報到、即時調整動線     |
| 名冊錯誤      | 健檢前確認名冊與員工資料     |
| 員工不清楚注意事項 | 健檢前7天與前1天提醒      |
| 現場不適或暈針   | 醫護人員處理，巡檢部門協助通報  |
| 報告領取爭議    | 事先確認報告交付方式       |
| 個資風險      | 個人報告僅給本人或依授權流程處理 |
| 企業端資料使用   | 僅提供去識別化統計        |
| ESG資料誤用   | 不將個人健康資料作為企業考核依據 |

馬偕醫院企業巡迴健檢服務，是由馬偕醫院企業巡檢部門協助企業規劃員工年度健康檢查，將健檢服務帶到企業現場，讓員工能在熟悉的工作場域完成健康檢查。
