# 馬偕企業巡檢案實際執行 SOP

**對外主責單位：馬偕醫院企業巡檢部門**

> 本 SOP 適用於馬偕醫院合作 OT 企業巡檢案。所有對企業客戶、員工、HR及管理層提供的正式文件、簡報、通知、報告與健康促進建議，均應以「馬偕醫院企業巡檢部門」為對外身份。

---

## 1. SOP 目的

本 SOP 用於7月企業巡迴健檢案的實際執行，協助馬偕醫院企業巡檢部門依固定步驟完成：

- 企業需求確認。
- 健檢方案確認。
- 合約及合作條件確認。
- 員工名冊收集。
- 場地與動線確認。
- 員工通知及預約分流。
- 健檢當日現場執行。
- 個人健檢報告交付。
- 去識別化團體統計分析。
- 健康講座及 ESG 健康促進後續追蹤。

### 使用方式

1. 專案啟動時，由專案負責人建立時程表與責任人。
2. 每個階段依本 SOP 的清單逐項確認。
3. 完成的項目應留下日期、負責人及確認紀錄。
4. 如有變更，應由馬偕醫院企業巡檢部門與企業指定窗口確認。
5. 健檢項目、醫療處置、報告判讀及追蹤建議，以馬偕醫院正式流程與醫療專業判斷為準。

## 4. 專案總流程

```text
企業需求確認
→ 健檢方案與報價確認
→ 合約／合作條件確認
→ 員工名冊格式確認
→ 場地與動線確認
→ 員工通知與預約分流
→ 健檢前提醒
→ 健檢當日執行
→ 個人報告交付
→ 去識別化團體統計
→ 健康講座與 ESG 健康促進建議
→ 年度追蹤與回顧
```

### 各階段完成標準

| 階段 | 完成標準 |
|---|---|
| 需求確認 | 人數、日期、地點、預算及需求已書面確認 |
| 方案確認 | 健檢項目、加選項目、費用及執行方式已確認 |
| 合作條件 | 合約、付款、取消及變更條件已確認 |
| 名冊確認 | 欄位格式、交付方式、期限及版本控管已確認 |
| 場地確認 | 場勘完成，動線、電力、隱私及設備條件可執行 |
| 員工通知 | 14天、7天及1天通知內容與發送窗口已確認 |
| 現場執行 | 人員、物資、檢體、設備及異常處理流程完備 |
| 報告交付 | 交付對象、方式、時程及查詢窗口明確 |
| 統計分析 | 資料去識別化、完整度檢查及小樣本保護完成 |
| 健康促進 | 健康議題、活動時程、KPI及年度追蹤方式已確認 |

## 5. 時程倒推表

以下以7月初開始執行為情境。若專案啟動時間不足30天，應由馬偕醫院企業巡檢部門召開壓縮排程會議，明確確認不可延誤項目。

| 時間 | 工作重點 | 負責單位 | 產出 |
|---|---|---|---|
| T-30～T-21 | 需求、人數、預算、日期及健檢項目確認 | 企業 HR＋馬偕醫院企業巡檢部門 | 需求確認表、方案草案、預定時程 |
| T-21～T-14 | 合作條件、名冊格式、場地及分流方式確認 | 企業 HR＋馬偕醫院企業巡檢部門 | 合作條件確認、名冊範本、場勘紀錄 |
| T-14～T-7 | 員工公告、預約表及健檢注意事項發送 | 企業指定窗口＋馬偕醫院企業巡檢部門 | 員工通知、預約名單、問題彙整 |
| T-7～T-3 | 名冊定稿、場地動線、人力及物資確認 | 雙方執行窗口＋馬偕醫療團隊 | 最終名冊、動線圖、人力表、物資表 |
| T-1 | 最後提醒、場地及臨時狀況確認 | 企業指定窗口＋馬偕醫院企業巡檢部門 | 最後提醒、執行確認紀錄 |
| T日 | 現場健檢執行 | 馬偕醫院企業巡檢部門＋馬偕醫療團隊 | 報到紀錄、完成紀錄、異常事件紀錄 |
| T+1～T+7 | 資料整理、檢體與異常事件確認 | 馬偕醫療團隊＋馬偕醫院企業巡檢部門 | 資料檢核紀錄、事件結案紀錄 |
| T+14～T+30 | 個人報告交付 | 馬偕醫療團隊／院方流程 | 個人報告交付通知 |

| T+45後 | 健康促進與 ESG 延伸 | 企業 HR＋馬偕醫院企業巡檢部門 | 12個月活動計畫、KPI及追蹤表 |

### 壓縮排程優先順序

1. 先確認健檢日期、員工人數、項目及場地是否可執行。
2. 再確認合約、報價、名冊格式及資料交付方式。
3. 名冊與員工通知不可晚於健檢前7天才首次處理。
4. 場勘、動線、人力及物資必須在健檢前3天完成最終確認。
5. 任何未確認的醫療項目不得於現場臨時承諾。

### 名冊管理原則

- 名冊由企業 HR 透過雙方確認的安全方式提供。
- 不得透過公開群組或無權限控管的連結傳送含個資名冊。
- 檔案應標示版本日期，例如：`企業名稱_健檢名冊_20260701_v3`。
- 每次更新應保留變更紀錄，避免多人各自使用不同版本。
- 最終名冊需由企業指定窗口確認。
- 企業端統計報告不得揭露姓名、員編、身分證、電話或個人健檢數值。
- 不收集與健檢執行或合法統計無關的敏感資料。

## 7. 場地與動線確認

### 現場空間

| 區域 | 功能 | 注意事項 |
|---|---|---|
| 報到區 | 身分核對、資料確認及分流 | 避免入口堵塞，名冊畫面不得讓無關人員看見 |
| 等候區 | 員工等待 | 保持通道暢通並可掌握叫號順序 |
| 量測區 | 身高、體重、腰圍及血壓 | 注意隱私及量測間距 |
| 抽血區 | 檢體採集 | 需有穩固桌椅、照明、耗材及鄰近休息空間 |
| 尿液區 | 尿液採集 | 確認廁所距離、標示及檢體交付方式 |
| 問診區 | 醫師或醫療人員問診 | 需有談話隱私，避免他人聽見 |
| 檢查區 | 依方案安排檢查 | 符合設備、電力、空間及隱私需求 |
| 休息區 | 暈針或身體不適員工休息 | 方便醫療人員照看，不得阻塞主要動線 |
| 物資區 | 存放表單、耗材及設備 | 應限制非工作人員接觸 |
| 檢體暫存區 | 依院方規範暫存檢體 | 需清楚標示並由指定人員管理 |
| 出口區 | 完成確認及離場 | 確認檢查無漏項，避免與報到人流交叉 |

```text
入口

→ 完成核對
→ 出口
```

## 10. 報告交付 SOP

### 交付原則

- 個人健檢報告交付員工本人，或依合法授權流程處理。
- 企業 HR 不應取得個別員工完整健檢報告。
- 報告交付方式、查詢方式及預計完成時間須於健檢前確認。
- 報告完成時間依馬偕醫院實際作業流程辦理。
- 員工如有異常，應依個人報告及醫師建議追蹤。
- 不應由企業主管要求員工提供個人健檢報告。
- 企業如需掌握整體健康議題，應使用去識別化團體統計報告。

## 11. 企業員工健檢統計分析 SOP

### 分析流程

```text
去識別化資料整理
→ 資料完整度檢查
→ 年齡／性別／部門結構分析
→ 異常率統計
→ 主要健康議題排序
→ 生活型態風險分析
→ 高風險方向整理
→ 健康促進建議
→ ESG 指標建議
→ 報告交付 HR
```

### 各步驟作業

| 步驟 | 作業內容 | 完成標準 |
|---|---|---|
| 1. 去識別化 | 移除姓名、員編、身分證、電話、地址及其他可識別欄位 | 分析檔不含直接識別資料 |
| 2. 完整度檢查 | 檢查受檢人數、缺失值、重複資料及欄位格式 | 列出可分析及不可分析項目 |
| 3. 結構分析 | 整理年齡、性別、部門及職務分布 | 總人數與各分類加總一致 |
| 4. 異常率統計 | 依院方判讀或正式標準計算異常人數及比例 | 分母、分子及資料期間清楚 |
| 5. 健康議題排序 | 依異常率、嚴重性、影響人數及可介入性排序 | 形成優先議題清單 |
| 6. 生活型態分析 | 整理運動、睡眠、壓力、抽菸、飲酒及痠痛等 | 未提供資料者明確標示 |
| 7. 高風險方向 | 整理需優先追蹤的健康方向，不提供個人名單 | 僅呈現團體趨勢及追蹤原則 |
| 8. 健康促進建議 | 將統計結果轉為講座、活動及職場改善措施 | 每項建議可對應統計依據 |
| 9. ESG指標 | 建立參與率、覆蓋率、滿意度及執行率等指標 | 指標定義及計算方式清楚 |
| 10. 報告交付 | 由馬偕醫院企業巡檢部門提供 HR 團體報告 | 已完成合規及小樣本檢查 |

### 常見統計項目

- BMI過高率。
- 腰圍過高率。
- 血壓偏高率。
- 空腹血糖偏高率。
- HbA1c偏高率。
- 總膽固醇、LDL-C、HDL-C及三酸甘油脂異常率。
- 肝功能異常率。
- 脂肪肝比例。
- 尿酸偏高率。
- 腎功能異常率。
- 運動不足比例。
- 壓力或睡眠問題比例。
- 肩頸腰背痠痛比例。

### 異常率計算原則

```text
異常率 ＝ 該項目異常人數 ÷ 該項目有效分析人數 × 100%
```

若某項檢查並非所有員工都有執行，分母應使用該項目的有效分析人數，不應直接使用全體受檢人數。

### 小樣本保護原則

- 部門、職務或族群人數過少時不單獨揭露。
- 可將相近部門或工作型態合併為較大類別。
- 若合併後仍可能推測個人，僅呈現企業整體統計。
- 不提供可反推姓名、員編、職務或個別健康狀況的交叉表。
- 團體風險分級不等於個人疾病診斷。
- 缺少個人交叉資料時，不得自行推算同時具備多項異常的人數。

## 14. 對企業 HR 的溝通話術

### 14.1 為什麼企業只能取得去識別化統計

「員工健檢資料屬於個人健康資訊，企業健康管理的目的，是掌握整體健康趨勢，而不是查看個別員工的檢查結果。因此，馬偕醫院企業巡檢部門提供給企業的是去識別化團體統計，讓公司可以規劃健康活動，同時保護員工隱私。」

### 14.2 為什麼不能提供個別員工異常名單

「個別異常結果應由員工本人依健檢報告及醫師建議追蹤。若直接把異常名單提供給企業，可能造成隱私風險，也可能讓健康資料被不當用於人事管理。因此企業端不取得個別名單，個人追蹤由醫療單位依合法流程處理。」

### 14.3 健檢統計如何轉換成健康促進活動

「團體統計可以找出影響人數較多的健康議題，例如運動不足、血脂、體重、壓力睡眠或肩頸腰背痠痛。企業可依優先順序安排講座、運動活動、飲食衛教、人體工學改善及自願追蹤提醒，讓健檢結果轉為可執行的年度計畫。」

### 14.4 ESG 健康指標如何呈現

「ESG健康指標建議呈現健檢參與率、健康講座參與率、活動覆蓋率、員工滿意度及年度活動執行率。這些指標能反映企業投入員工健康與福祉的程度，又不需要揭露個人健康結果。」

### 14.5 員工個人異常應如何追蹤

「員工收到個人健檢報告後，應依報告內容及醫師建議安排複檢、門診或生活調整。企業可以提供健康資源及自願參與的提醒，但不應要求員工交出個人報告，也不應追問個人診斷或檢驗數值。」

## 15. 合規與資料保護提醒

### 醫療與健康表述

- 不可直接診斷疾病。
- 不可使用團體統計判定個別員工疾病。
- 不可宣稱健檢可保證預防疾病。
- 不可宣稱健康促進活動可保證改善疾病或檢驗數值。
- 健檢及統計分析不取代醫師診斷。
- 員工個人異常應依個人報告與醫師建議追蹤。

### 個資與健康資料

- 個人健檢報告不得提供企業端。
- 企業端僅取得去識別化團體統計。
- 不得將健康資料用於績效、升遷、聘僱或懲處。
- 不得要求員工向主管提供個人健檢報告。
- 小樣本資料需合併或不揭露。
- 不提供可推測個別員工健康狀況的交叉分析。
- 名冊及健康資料應使用安全方式傳輸、保存及限制存取。
- 資料使用應符合目的明確及最少必要原則。

### 同意與授權

- 涉及個人追蹤、轉介或額外資料使用時，需取得員工本人同意。
- 同意內容應說明使用目的、資料範圍、使用期間及接收對象。
- 員工不同意個人追蹤時，不應影響其工作權益。
- 未經本人同意，不得將個人健康資料提供未授權第三方。

### 正式聲明

> 本 SOP 所涉及之團體健康分析與健康促進建議，僅供企業健康管理規劃參考，不取代醫師診斷。企業端僅可取得去識別化團體統計資料，不應取得個別員工健檢結果，亦不得將健康資料作為績效、升遷、聘僱或懲處依據。
