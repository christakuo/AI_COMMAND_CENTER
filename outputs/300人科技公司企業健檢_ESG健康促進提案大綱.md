# 300人科技公司企業健檢＋ESG健康促進提案大綱

> 提案角色：馬偕醫院巡檢健管顧問  
> 目前已知條件：科技業，員工約300人  
> 說明：本文件為初步提案架構，尚未假設員工年齡、預算及工作地點。

## 一、提案架構

### 提案核心目標

1. 完成300名員工年度健康檢查。
2. 降低久坐、代謝、壓力及睡眠等健康風險。
3. 建立健檢後的健康分級與追蹤機制。
4. 將健康促進活動轉換為可記錄的ESG成果。
5. 建立企業年度健康管理制度，而非只完成單次健檢。

## 二、服務模組

| 模組 | 服務內容 | 預期成果 |
|---|---|---|
| 需求盤點 | 員工結構、職務、健康需求及場地訪談 | 確認健檢與健康促進方向 |
| 基礎健檢 | 依法規及企業需求規劃檢查項目 | 完成員工基本健康篩檢 |
| 進階健檢 | 依年齡、性別及健康風險提供加選項目 | 提升疾病早期發現機會 |
| 主管健檢 | 高階主管個人化健檢規劃 | 強化主管健康管理 |
| 巡迴健檢 | 到企業現場執行報到、檢查及動線管理 | 降低員工外出及企業行政成本 |
| 報告分析 | 提供個人報告及AI輔助健康分析 | 協助員工理解健康風險 |
| 健康分級 | 依檢查結果區分不同健康風險層級 | 建立優先追蹤名單 |
| 健康顧問 | 提供衛教、複檢提醒及醫療資源媒合 | 提高異常追蹤率 |
| 健康促進 | 規劃講座、運動、壓力及慢病預防活動 | 改善員工健康行為 |
| ESG成果 | 彙整參與率、異常追蹤及活動成果 | 支援企業永續報告揭露 |

### 建議健康促進主題

- 久坐與肩頸腰背問題
- 三高與代謝症候群預防
- 壓力、睡眠與心理健康
- 規律運動及體重管理
- 女性與男性常見健康風險
- 中高齡員工健康支持
- 家庭照護及長照資源介紹

## 三、執行流程

```text
企業需求訪談
      ↓
員工與職務資料盤點
      ↓
設計分級健檢方案
      ↓
預約及巡檢場地規劃
      ↓
企業現場巡迴健檢
      ↓
健檢報告與AI分析
      ↓
員工健康風險分級
      ↓
健康顧問追蹤與轉診建議
      ↓
健康講座及促進活動
      ↓
年度成效與ESG成果報告
```

### 執行SOP

| 階段 | 執行重點 |
|---|---|
| 1. 企業需求訪談 | 確認人數、據點、班別、預算、場地及服務需求 |
| 2. 員工資料盤點 | 分析年齡、性別、職務型態及過往健康風險 |
| 3. 健檢方案設計 | 規劃基礎、進階及高階主管健檢方案 |
| 4. 巡迴健檢執行 | 安排預約分流、現場動線、人力及異常處理窗口 |
| 5. 報告分析 | 提供個人健檢報告及AI輔助健康分析 |
| 6. 健康分級 | 依風險程度建立健康管理與優先追蹤名單 |
| 7. 健康促進活動 | 依企業整體健康風險規劃講座與促進活動 |
| 8. 成效報告 | 統計健檢完成率、活動參與率及異常追蹤率 |
| 9. ESG成果整理 | 彙整年度健康投入、執行成果及改善計畫 |

## 四、ESG連結方式

本案以ESG中的 **S：員工健康與福祉** 為核心，並延伸連結E與G。

| ESG面向 | 連結方式 | 可整理成果 |
|---|---|---|
| E：環境 | 建立健康職場，改善久坐及工作環境相關健康風險 | 健康環境改善措施、活動紀錄 |
| S：社會 | 推動員工健檢、健康促進、心理健康及家庭照護支持 | 健檢涵蓋率、活動參與率、追蹤完成率 |
| G：治理 | 建立年度健康政策、分級追蹤及成效檢討制度 | 健康管理流程、年度報告、改善計畫 |

### 建議追蹤指標

- 員工健檢完成率
- 健康促進活動參與率
- 健檢異常員工完成追蹤率
- 健康講座滿意度
- 高風險族群管理人數
- 年度健康風險變化
- 健康政策及活動執行次數

> 個人健康資料應依隱私及資訊安全原則管理。企業ESG成果建議使用匿名化、群體化統計資料，避免揭露個別員工健康資訊。

## 五、需要補充的資料

| 項目 | 需要確認的內容 |
|---|---|
| 企業基本資料 | 企業名稱及主要營運地點 |
| 員工資料 | 員工年齡、性別及部門分布 |
| 工作型態 | 辦公室、研發、產線、輪班或遠距工作比例 |
| 執行據點 | 300名員工是否集中於同一地點 |
| 健檢需求 | 需要法定健檢、進階健檢或兩者並行 |
| 執行方式 | 是否確定採用企業現場巡迴健檢 |
| 過往紀錄 | 過去健檢參與率及主要異常項目 |
| 主管方案 | 是否需要獨立的高階主管健檢方案 |
| 健康促進 | 預計安排的健康講座或活動場次 |
| 後續管理 | 是否需要健康顧問及高風險員工追蹤 |
| ESG需求 | 是否需要納入永續報告或ESG評鑑資料 |
| 執行條件 | 預計執行月份及預算範圍 |
